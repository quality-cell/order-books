# Веб-приложение по заказу книг в библиотеке

# Для запуска проекта необходимо:

1. Установить Docker на свой компьютер, если он еще не установлен
2. Клонировать проект из репозитория с помощью команды git clone https://github.com/quality-cell/order-books.git
3. Запустите Docker и запустите docker-compose.yml файл (docker-compose up)
4. Выполните mvn clean package
5. Выполните java -jar order-books-1.0.jar 
6. Переходим на главную страницу http://localhost:8080/
7. Чтобы получить json со список заказов по клиентам http://localhost:8080/book-order/by-client

# Функционал:

1. Добавить клиента
2. Редактировать клиента
3. Удалить клиента
4. Получить весь список клиентов 
5. Добавить автора 
6. Редактировать автора 
7. Удалить автора 
8. Получить весь список автора 
9. Добавить книгу 
10. Редактировать книгу 
11. Удалить книгу 
12. Получить весь список книг 
13. Добавить заказ 
14. Редактировать заказ 
15. Удалить заказ 
16. Получить весь список заказов 
17. Получить список заказов по клиентам

# Технологии:

1. jdk 1.8
2. Spring Boot 2.7.18
3. PostgreSQL 14.9
4. Maven
