# Веб-приложение по заказу книг в библиотеке

# Для запуска проекта необходимо:

1. Установить Dcoker на свой компьютер, если он еще не установлен
2. Клонировать проект из репозитория с помощью команды git clone https://github.com/quality-cell/FilteringStudents.git
3. Запустите Docker и запустите docker-compose.yml файл
5. Выполните mvn clean package
6. Выполните java -jar order-books-1.0.jar 
7. Переходим на главную страницу http://localhost:8080/

# Функционал:

1. Добавить клинета
2. Редактировать клинета
3. Удалить клинета
4. Получить весь список клиентов
7. Добавить книгу
8. Редактировать книгу
9. Удалить книгу
10. Получить весь список книг
11. Добавить заказ
12. Редактировать заказ
13. Удалить заказ
14. Получить весь список заказов
15. Получить список заказов по клиентам
